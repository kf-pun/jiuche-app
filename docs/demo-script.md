## 一、開發用意（Why we built this）

### 背景問題
台灣通勤族高度依賴自駕，大量車輛單人行駛造成：
- **通勤成本昂貴**：油資、停車費、車輛折舊全由一人承擔
- **塞車嚴重**：大台北地區每天通勤尖峰極端壅塞
- **共乘市場缺口**：Uber 屬商業載客，法規灰色地帶；既有共乘 App 收費透明度低

### 解決方案
「揪車」讓順路的駕駛與乘客**媒合共乘**，費用依台灣交通部法規計算，做到：
- 乘客分攤油資，**每趟通勤省下 30–60%**
- 司機油資有人分擔，**開車不再虧本**
- 平台合法合規，**非商業載客，無執照爭議**

## 三、車費計算方式（Fare Calculation）

這是揪車最核心也最有法律意義的設計。

### 計算公式

```
法定油資上限 = 行車距離（km） × 油耗（L/km） × 當週油價（NT$/L） ÷ 共乘人數
```

### 三層數據來源

1. **行車距離** — Google Maps Directions API 即時計算，司機填寫起訖點後自動帶入
2. **油耗** — 依車型類別查交通部官方表（8 種類別，司機不得自填，防止虛報）

   | 車型類別 | 油耗（L/km） | 油號 |
   |---------|------------|------|
   | 小型轎車 | 0.068 | 95 |
   | 中型轎車 | 0.080 | 95 |
   | 大型轎車 | 0.095 | 98 |
   | SUV（小） | 0.090 | 95 |
   | SUV（大） | 0.110 | 98 |
   | MPV/廂型 | 0.100 | 95 |
   | 皮卡/貨卡 | 0.115 | 98 |
   | 電動車 | N/A | N/A |

3. **當週油價** — 每週四自動呼叫 **data.gov.tw 能源局 API**（官方資料，非爬蟲），更新 92/95/98 三種油號油價存入資料庫

### 服務費三段分級

| 行車距離 | 乘客付服務費 |
|---------|------------|
| ≤ 10 km | NT$10 |
| 11–30 km | NT$15 |
| > 30 km | NT$20 |

**乘客總付款 = 油資 + 服務費**（司機輸入票價超過上限時，系統即時阻擋）

## 四、營收來源（Revenue Model）

| 項目 | 說明 | 預估單筆 |
|------|------|---------|
| **每筆服務費** | 乘客每次預訂收取 NT$10–20，依距離分級 | NT$10–20 |
| **司機履約保證金** | 新加入司機繳交保證金（虛假取消扣款），提升媒合品質 | NT$500–1,000（一次性）|
| **置頂廣告 / 精選行程** | 司機付費讓行程在搜尋結果優先顯示 | 每次 NT$15–30 |
| **B2B 企業訂閱（未來）** | 企業包月方案：員工免服務費 + ESG 報告 + CSV 報帳 | 月費 NT$5,000–30,000 |
| **碳權憑證（未來）** | 累積平台 CO₂ 減排量，轉換碳抵銷憑證販售給企業 | — |

### 單位經濟模型（示意）

```
假設每日媒合 1,000 趟、平均距離 25 km（服務費 NT$15）

每日服務費收入 = 1,000 趟 × NT$15 = NT$15,000
每月營收        = NT$450,000
```

## 五、使用技術（Tech Stack）

### 前端
- **Next.js 15**（App Router） + **TypeScript** — 型別安全、Server Actions
- **Tailwind CSS v4** — Mobile-First，主色 green/emerald 漸層

### 後端 & 資料庫
- **Supabase** — PostgreSQL + RLS（Row Level Security）+ Auth（OTP / Google OAuth）
- **Server Actions** — 統一資料存取層，`src/actions/` 目錄管理
- **8 張核心資料表**：users / rides / bookings / reviews / wallet_transactions / notifications / system_config / companies

### 外部 API 整合
- **Google Maps Platform**（4 個 API）：Places Autocomplete / Geocoding / Directions / Maps JavaScript
- **ECPay**：信用卡 / ATM / 超商代碼儲值（SHA256 CheckMacValue）
- **data.gov.tw 能源局 API**：每週四自動油價更新

### 部署 & 自動化
- **Vercel**：前台 + 後台同一 repo，Edge Runtime
- **Vercel Cron**：`/api/cron/update-fuel-price`，每週四 01:00 UTC 自動執行

## 六、功能模塊 Demo 路線

建議依此順序展示（約 5 分鐘）：

### 🔍 1. 乘客搜尋共乘（1 分鐘）
- 首頁輸入起訖點（地址自動完成）
- 點擊 📍 GPS 定位自動填入出發地
- 搜尋結果：篩選（時間/價格）、排序
- 行程詳情：**路線地圖**（Google Maps 路線折線 + 距離 + 行車時間）、司機評分與歷史評價

### 💳 2. 預訂 & 費用透明化（1 分鐘）
- 選擇座位數 → 預訂確認頁
- 費用明細：**油資 NT$X + 服務費 NT$Y = 總計 NT$Z**
- 確認付款（扣錢包餘額）→ 預訂成功動畫

### 🚗 3. 司機發布行程（1 分鐘）
- 起訖點選擇 → **地圖選點 Modal**（拖曳大頭針選點）
- 系統自動計算距離 → 顯示**法定油資上限 NT$XXX**
- 輸入票價超過上限 → 系統即時阻擋（紅框 + 警告）
- 設定日期（單日 / 工作日 / 每日）、時間、座位數

### 💰 4. 錢包 & 儲值（30 秒）
- 餘額總覽、本月收支
- 交易記錄（油資收入 / 乘車支出）
- 儲值：信用卡 / ATM / 超商（ECPay 串接）

### 🖥️ 5. 後台管理（1 分鐘）
- Dashboard：今日訂單 / 用戶 / 金流 KPI
- 訂單管理：手動取消 + 自動退款 + 發通知
- 金流管理：交易列表 + 補償交易 + 匯出 CSV
