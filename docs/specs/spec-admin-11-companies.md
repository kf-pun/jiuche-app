# 企業管理（B2B）功能規格書

**版本：** v1.0
**日期：** 2026-03-18
**狀態：** 已確認

---

## 1. 背景與目標

揪車平台以企業為主要客戶，同一間公司的員工會共同使用平台共乘。目前後台缺乏以「企業」為單位的管理視角，客服無法快速掌握某間公司的整體使用狀況，也無法提供企業主管所需的費用報表。

目標：
- 讓管理員能以企業為單位，瀏覽員工數、CO₂ 貢獻、月消費等彙總資訊
- 支援進入單一企業查看員工名單與個別狀態
- 提供費用報帳 CSV 匯出，供企業主管報帳或財務對帳

---

## 2. 使用者故事

- 身為管理員，我希望看到所有企業的清單，這樣才能快速掌握哪些公司是平台主要用戶
- 身為管理員，我希望點進某間公司後看到員工名單，這樣才能處理特定員工的帳號問題
- 身為管理員，我希望能匯出某間公司的消費明細 CSV，這樣才能提供給企業財務部門對帳
- 身為管理員，我希望能看到每間企業的 CO₂ 減碳累計，這樣才能支援企業 ESG 報告需求

---

## 3. 功能範圍

### 已完成功能
- 後台 Layout（左側導覽 + 主內容區）
- AdminGuard（非 admin 無法進入後台）
- `users` 表有 `company` 欄位（字串），可作為分組依據

### 待製作
- 企業列表頁（`/admin/companies`）：以 `users.company` 分組統計
- 企業詳情頁（`/admin/companies/[company]`）：企業資訊 + 員工列表
- 費用報帳匯出 CSV 功能（按企業過濾 `wallet_transactions`）
- 後台左側導覽新增「企業管理」項目

---

## 4. 使用流程

### 企業列表
1. 管理員點擊左側導覽「企業管理」
2. 系統載入所有企業（以 `users.company` 分組）
3. 顯示企業卡片列表，支援搜尋企業名稱
4. 點擊企業名稱 → 進入企業詳情頁

### 企業詳情
1. 進入 `/admin/companies/[company]`（company 為 URL encode 後的企業名稱）
2. 頂部顯示企業彙總資訊（員工數、CO₂、本月支出）
3. 下方顯示員工列表（分頁，每頁 20 筆）
4. 點擊「匯出費用報帳 CSV」→ 下載該企業所有員工的消費明細

### 例外情況
- 企業名稱為空（`users.company = ''` 或 `null`）的用戶不顯示在列表中
- 無任何企業資料：顯示空狀態提示

## 5. 畫面與功能說明

### 5.1 企業列表頁 `/admin/companies`

- **需要登入：** 是（AdminGuard）
- **畫面內容：**
  - 頁面標題「企業管理」+ 總企業數
  - 搜尋框（搜尋企業名稱）
  - 企業表格，每列包含：

    | 欄位 | 說明 |
    |------|------|
    | 企業名稱 | 可點擊連結進入詳情 |
    | 員工數 | 該公司 users 筆數 |
    | CO₂ 減碳（kg） | 員工 co2_total 加總 |
    | 本月消費（NT$） | 當月 wallet_transactions payment 類型負值加總 |
    | 狀態 | 正常（有活躍員工）/ 停用（所有員工皆停權） |

  - 分頁（每頁 20 筆）
- **空狀態：** 顯示「目前尚無企業資料」

### 5.2 企業詳情頁 `/admin/companies/[company]`

- **需要登入：** 是（AdminGuard）
- **畫面內容：**
  - 返回按鈕 → `/admin/companies`
  - 頁面標題：企業名稱
  - 頂部 3 格 KPI 卡片：員工數 / 累計 CO₂ / 本月支出
  - 「匯出費用報帳 CSV」按鈕
  - 員工列表表格：

    | 欄位 | 說明 |
    |------|------|
    | 姓名 | 連結至 `/admin/users/[id]` |
    | 手機 | 顯示 `phone` |
    | 加入日期 | `created_at` 格式化 |
    | 餘額 | NT$ |
    | 角色 | user / admin（色標） |
    | 狀態 | 正常 / 停權（色標） |

  - 分頁（每頁 20 筆）

### 5.3 費用報帳 CSV 匯出

- 觸發：企業詳情頁點擊「匯出費用報帳 CSV」
- 篩選：該企業所有員工的 `wallet_transactions`（所有類型、全部歷史）
- CSV 欄位（含 UTF-8 BOM）：

  ```
  日期, 員工姓名, 類型, 金額(NT$), 說明
  2026-03-15, 王小明, payment, -120, 行程付款
  ```

- 類型對照：topup=儲值 / payment=行程付款 / refund=退款 / earning=收入 / adjustment=手動調整
- 金額：原始值（含正負號）
- 檔名：`jiuche_expenses_{企業名稱}_{YYYY-MM}.csv`

---

## 6. 資料說明

- **資料來源：** Supabase `users` 表（company 欄位分組）+ `wallet_transactions` 表
- **無新增欄位**（使用現有 schema）
- 企業分組以 `users.company` 字串值為鍵，不另建 companies 表
- 需使用 `createServiceClient()` 繞過 RLS

---

## 7. 設計規範

- 後台風格：`bg-gray-50` 頁面底、`bg-white rounded-xl shadow-sm` 卡片
- 桌機操作（最小寬度 1280px），無 BottomNav
- 狀態標籤：正常=綠色、停用=紅色、admin=紫色
- 載入中：表格區域顯示 spinner
- 危險操作：本頁無（匯出 CSV 不需二次確認）

---

## 8. 備註

- `users.company` 為自由輸入字串，同一企業若拼法不同會被視為不同企業（後續可考慮正規化，目前不處理）
- 企業名稱為空值的用戶不顯示於列表中
- 本月消費金額僅計算 `type = 'payment'` 的負值交易
- CSV 匯出全部歷史，不限日期範圍（未來可擴充篩選）
