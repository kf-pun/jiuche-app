## 1. 背景與目標

目前起訖點輸入只有文字自動完成，使用者必須準確輸入地名才能搜尋，對不熟悉地址的人不友善，也無法得知行車距離與預計時間。此外，原有車費計算缺乏法規依據與透明度。

**目標：**
- 透過地圖選點與 GPS 定位，讓起訖點輸入零打字即可完成
- 自動計算路線距離與行車時間，提升行程資訊透明度
- 建立合法合規的費用架構：司機收油資分攤、平台向乘客收服務費、企業包月免員工服務費

---

## 2. 使用者故事

- 身為**乘客**，我希望點一下「定位」就能自動填入目前位置，這樣才能省去手動輸入出發地的麻煩。
- 身為**乘客**，我希望在地圖上點選目的地，這樣才能精準選到沒有固定地名的地點（如公司大樓側門）。
- 身為**乘客**，我希望在行程詳情看到路線地圖與行車時間，這樣才能評估是否值得搭乘。
- 身為**司機**，我希望發布行程時系統自動建議合理油資分攤上限，確保收費合法又省事。
- 身為**企業 HR**，我希望員工搭乘無需另付服務費，這樣才能作為員工福利推廣共乘。

## 4. 費用架構

### 法規說明
依台灣法規，共乘費用不得超過「合理分攤油資 + 過路費」。司機不得以共乘營利，只能收回成本。平台可另向乘客收取「媒合服務費」。

### 油資上限計算公式
```
油資上限（每位乘客）= (距離 km × 油耗係數 × 油價) ÷ 乘客數 + 過路費分攤
預設參數：油耗係數 0.1 L/km，油價 32 元/L
範例：10km，2 人共乘 → (10 × 0.1 × 32) ÷ 2 = $16 油資上限
```

### 費用角色分配

| 角色 | 散客模式 | 企業員工模式 |
|------|---------|------------|
| **乘客付** | 油資分攤 + 平台服務費 $15 | 油資分攤（無服務費） |
| **司機收** | 油資分攤全額（無扣除） | 油資分攤全額（無扣除） |
| **平台收** | 乘客服務費 $15/趟 | 企業月費（涵蓋員工服務費） |

> 平台服務費金額（$15）為預設值，後台可設定調整。

### 企業判斷邏輯
- 乘客的 `users.company` 對應到 `companies` 表中 `subscription_active = true` 的企業 → 免服務費
- 否則視為散客 → 收服務費 $15

## 5. 使用流程

### 5-1 GPS 定位（首頁 / 發布行程）

1. 使用者點擊出發地欄位旁的「📍 定位」按鈕
2. 瀏覽器彈出定位授權請求
3. **授權成功**：呼叫 Geocoding API 將座標轉為地址，自動填入出發地欄位
4. **授權拒絕 / 逾時**：顯示提示「無法取得位置，請手動輸入」，欄位維持空白

### 5-2 地圖選點 Modal

1. 使用者點擊起點或終點欄位右側的「🗺 地圖」按鈕
2. 全螢幕 Modal 開啟，頂部有搜尋框（複用 Places autocomplete），地圖佔據中間
3. 搜尋地點後地圖自動跳到該位置並落下大頭針；也可直接點擊地圖任意位置
4. 底部顯示反查後的地址文字
5. 點擊「確認」→ Modal 關閉，地址與座標帶回欄位
6. 點擊「取消」→ Modal 關閉，欄位不變

### 5-3 路線預覽（行程詳情頁）

1. 頁面載入，取得起訖點座標
2. 呼叫 Directions API 計算路線（開車模式）
3. 顯示地圖卡片：藍線路線 + 起點綠色大頭針 + 終點紅色大頭針
4. 卡片下方顯示距離（km）與預計行車時間
5. **無 API Key** 或**舊行程（無座標）**：隱藏地圖卡片，向下相容

### 5-4 車費設定（發布共乘頁）

1. 司機填入起訖點後（含座標），自動呼叫 Directions API
2. 系統計算「合法油資上限」並顯示提示，例：「法定上限：$XX（依 Xkm 估算）」
3. 票價欄位預填上限值，司機可調低但**不得超過上限**（超過時欄位變紅並阻擋送出）
4. 送出時一併寫入 `distance_km`、`duration_minutes`、座標欄位

### 5-5 預訂確認頁費用拆分

```
散客：
  油資分攤     $XX
  平台服務費   $15
  ─────────────
  合計         $XX

企業員工：
  油資分攤     $XX
  服務費       $0（企業包月）
  ─────────────
  合計         $XX
```

## 6. 畫面與功能說明

### 首頁（`/`）
- 出發地欄位右側新增「📍」圖示按鈕（綠色，`text-green-600`）
- 起訖點欄位右側另有「🗺」按鈕，點擊開啟地圖選點 Modal
- **需要登入**：否

### 地圖選點 Modal（共用元件 `MapPickerModal`）
- 全螢幕遮罩 `bg-black/50`，白色底部抽屜 `rounded-t-2xl` 高度 85vh
- 頂部搜尋框（Places autocomplete，高度 48px）
- 地圖佔滿中間，底部顯示地址文字 + 「確認」/「取消」按鈕
- 拖曳大頭針時地址即時更新（debounce 500ms）
- 載入中：灰色骨架屏

### 發布共乘（`/post`）
- Step 1 起訖點：每個欄位右側增加「地圖」按鈕；出發地旁有「📍 定位」按鈕
- 起訖點填入後顯示：「預計 X km，約 Y 分鐘 ｜ 法定上限 $XX」
- 票價欄位超過上限時：紅框 + 「超過法定油資上限，請調低票價」錯誤文字
- **需要登入**：是（AuthGuard 保護）

### 預訂確認（`/booking/confirm`）
- 費用區塊拆分為「油資分攤」+「平台服務費」兩行
- 企業員工：服務費顯示 $0 並標注「企業方案」
- **需要登入**：是

### 行程詳情（`/results/[id]`）
- 司機資訊卡片下方新增「路線地圖」卡片（高度 200px，`rounded-xl overflow-hidden shadow-sm`）
- 地圖：藍線路線 + 起終點大頭針
- 卡片下方：🛣 `X km` ｜ 🕐 `約 Y 分鐘`（`text-sm text-gray-500`）
- 載入中：骨架屏；無座標：隱藏卡片
- **需要登入**：否

## 7. 資料說明

### DB 新增欄位（`rides` 表）

| 欄位 | 型別 | 說明 |
|------|------|------|
| `origin_lat` | NUMERIC(10,7) | 起點緯度（可為 NULL） |
| `origin_lng` | NUMERIC(10,7) | 起點經度（可為 NULL） |
| `destination_lat` | NUMERIC(10,7) | 終點緯度（可為 NULL） |
| `destination_lng` | NUMERIC(10,7) | 終點經度（可為 NULL） |
| `distance_km` | NUMERIC(6,2) | 路線距離公里數（可為 NULL） |
| `duration_minutes` | INTEGER | 預計行車分鐘數（可為 NULL） |
| `fare_limit` | INTEGER | 法定油資上限（可為 NULL） |

### DB 新增欄位（`bookings` 表）

| 欄位 | 型別 | 說明 |
|------|------|------|
| `service_fee` | INTEGER | 平台服務費（散客 15，企業員工 0） |

### DB 新增欄位（`companies` 表）

| 欄位 | 型別 | 說明 |
|------|------|------|
| `subscription_active` | BOOLEAN | 企業訂閱是否有效（預設 false） |
| `subscription_expires_at` | TIMESTAMPTZ | 訂閱到期時間（可為 NULL） |

Migration 檔：`supabase/migrations/002_add_map_fields.sql`

### 新增 API 代理路由

| 路由 | 說明 |
|------|------|
| `/api/directions` | 代理 Google Directions API |
| `/api/geocode` | 代理 Google Geocoding API（座標 → 地址） |

### 環境變數
`NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`（需在 GCP 額外啟用 Maps JavaScript API、Directions API、Geocoding API）

## 9. 備註

- 油耗係數（0.1 L/km）與油價（32 元/L）為系統預設值，後台可調整
- 平台服務費（$15/趟）為預設值，後台可調整
- Directions API 計費：每 1,000 次請求約 $5 USD；發布行程與行程詳情各呼叫一次
- 建議安裝套件：`@googlemaps/js-api-loader`（統一管理 Maps script 載入）
- GPS 定位僅用於出發地；終點依使用者習慣手動輸入或地圖選點
- 企業訂閱管理由後台 `/admin/companies` 操作（`subscription_active` 開關）
- 行程詳情路線地圖固定使用「開車」模式（符合共乘使用情境）
