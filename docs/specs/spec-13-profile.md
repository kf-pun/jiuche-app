# 個人資料頁 功能規格書

**版本：** v1.0
**日期：** 2026-03-17
**狀態：** 已確認

---

## 1. 背景與目標

### 背景
使用者需要一個集中管理個人帳號的頁面，用來查看自己的共乘統計、錢包餘額、環保貢獻，以及前往各功能設定的入口。個人資料頁也是「未登入者」的登入引導入口。

### 目標
1. 讓已登入使用者一眼看到個人統計數據與帳號狀態
2. 提供所有帳號相關功能的快速導覽入口
3. 讓未登入使用者在此頁看到登入引導，而非直接空白或跳轉

---

## 2. 使用者故事

- 身為**一般乘客**，我希望快速看到自己的共乘次數與減碳量，這樣才能感受到自己對環保的貢獻
- 身為**司機**，我希望在個人頁看到我的車輛資訊捷徑，這樣才能確認車輛設定是否正確
- 身為**未登入訪客**，我希望個人頁有清楚的登入按鈕，這樣才能知道如何開始使用平台

---

## 3. 功能範圍

### 已完成功能
- **未登入狀態**：顯示使用者圖示、「尚未登入」說明與「立即登入」按鈕
- **Header 區塊**（已登入）：頭像（姓名首字）、姓名、公司、手機號碼、「編輯」連結按鈕
- **統計數據列**：共乘次數（趟）、累計減碳（kg）、評分（★）
- **錢包餘額卡**：顯示餘額，點擊導向 `/wallet`，右側「儲值」標籤
- **帳號設定選單**：個人資料（→ `/profile/edit`）、車輛資訊（司機才顯示，→ `/profile/car`）、我的錢包（→ `/wallet`）、通知設定（→ `/notifications`）
- **環保貢獻選單**：ESG 減碳儀表板（→ `/esg`，右側顯示累計 kg）
- **其他選單**：客服中心、關於揪車、登出（紅色）
- **版本號**：頁面底部顯示 `v0.1.0 Prototype`
- 登出後呼叫 `logout()` 並導向首頁 `/`

### 待製作
- `/profile/car`（車輛資訊頁）尚未建立，目前為無效連結
- 「客服中心」與「關於揪車」為外觀展示，點擊無實際動作

---

## 4. 使用流程

### 4.1 已登入使用者
1. 點擊底部導覽列「我的」圖示 → 進入 `/profile`
2. 查看個人統計（共乘次數、減碳量、評分）
3. 點擊錢包餘額卡 → 跳至 `/wallet`
4. 點擊「個人資料」→ 跳至 `/profile/edit`
5. 點擊「ESG 減碳儀表板」→ 跳至 `/esg`
6. 點擊「登出」→ 呼叫 `logout()`，跳回首頁 `/`

### 4.2 未登入訪客
1. 點擊底部導覽列「我的」圖示 → 進入 `/profile`
2. 看到「尚未登入」畫面與「立即登入」按鈕
3. 點擊「立即登入」→ 跳至 `/auth/login`

## 5. 畫面與功能說明

### 5.1 個人資料頁（已登入）

**路由：** `/profile`
**需要登入：** 否（未登入時顯示引導畫面，不跳轉）

**Header 區塊**（綠色漸層背景）
- 左側：頭像（16×16 圓角方形，姓名首字，白色半透明底）+ 姓名、公司、手機號碼
- 右側：編輯按鈕（鉛筆圖示，→ `/profile/edit`）
- 下方統計列（3 格等寬）：
  - 共乘次數（`user.totalRides` 趟）
  - 累計減碳（`user.co2Total.toFixed(1)` kg）
  - 評分（`user.rating.toFixed(1)` ★）

**錢包餘額卡**（浮出 Header 下方 `-mt-3`，白色圓角卡帶陰影）
- 左側：錢包圖示（綠色漸層圓角方形）＋「揪車錢包餘額」標籤 ＋ `NT$ {balance}` 粗體
- 右側：「儲值」綠色標籤 ＋ 箭頭
- 整張卡可點擊，導向 `/wallet`

**帳號設定卡片**（白色圓角卡）
- 區塊標題「帳號設定」
- 選單項目（各項右側顯示箭頭）：
  - 個人資料（右側顯示使用者姓名，→ `/profile/edit`）
  - 車輛資訊（**僅 `user.isDriver === true` 才顯示**，右側顯示車型+車牌，→ `/profile/car`）
  - 我的錢包（右側顯示餘額，→ `/wallet`）
  - 通知設定（→ `/notifications`）

**環保貢獻卡片**（白色圓角卡）
- 區塊標題「環保貢獻」
- ESG 減碳儀表板（右側顯示 `{co2Total} kg 累計`，→ `/esg`）

**其他卡片**（白色圓角卡）
- 客服中心（外觀展示，無動作）
- 關於揪車（外觀展示，無動作）
- 登出（紅色文字與圖示，點擊執行 `logout()` + 跳首頁）

**頁面底部**
- 版本號文字：`揪車 JiuChe v0.1.0 Prototype`（灰色小字，置中）

---

### 5.2 未登入引導畫面

**路由：** `/profile`（同路由，依登入狀態切換）

- 使用者圖示（綠色淡底圓形）
- 「尚未登入」標題
- 「登入後可查看個人資料與錢包」說明
- 「立即登入」主按鈕（→ `/auth/login`）

## 6. 資料說明

| 項目 | 說明 |
|------|------|
| `user` | 來自 `authContext`，讀取 `localStorage` key: `jiuche_user` |
| `isLoggedIn` | 來自 `authContext`，決定顯示登入引導或個人頁 |
| `user.totalRides` | DEFAULT_USER 預設值：假資料 |
| `user.co2Total` | DEFAULT_USER 預設值：28.4 kg（假資料） |
| `user.rating` | DEFAULT_USER 預設值：假資料 |
| `user.balance` | 來自 `authContext`，可被 `deductBalance` / `addBalance` 更新，為動態值 |

## 7. 設計規範

- 手機優先，畫面最寬 448px
- Header：`bg-gradient-to-br from-green-600 to-emerald-500 px-5 pt-12 pb-6`
- 頭像：`w-16 h-16 rounded-2xl bg-white/20`
- 統計格：`bg-white/15 rounded-2xl p-3 text-center`（白色半透明，在漸層背景上）
- 錢包卡：`-mt-3` 負 margin 讓卡片壓在 Header 上，製造層次感
- 選單項目底線：`border-b border-gray-50`，最後一項無底線（`last:border-0`）
- 危險項目（登出）：文字與圖示使用紅色（`text-red-400`），背景 `bg-red-50`
