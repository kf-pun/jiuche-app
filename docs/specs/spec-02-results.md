# 搜尋結果與篩選 功能規格書

**版本：** v1.0
**日期：** 2026-03-17
**狀態：** 已確認

---

## 1. 背景與目標

使用者從首頁輸入起訖點與日期後，需要一個清單頁面來瀏覽所有可搭乘的行程，並能依照個人需求快速縮小選擇範圍（例如：只看早班、只看女性司機、最便宜優先）。

**目標：**
- 讓使用者能一眼掃描所有符合條件的行程，快速決定要選哪一趟
- 透過排序與篩選，幫助不同需求的乘客找到最適合自己的行程
- 在沒有結果時給予明確提示，引導使用者調整條件

---

## 2. 使用者故事

- 身為**在意費用的上班族**，我希望能按價格由低到高排序，這樣才能選到最划算的共乘。
- 身為**重視安全感的女性乘客**，我希望能篩選只顯示女性司機的行程，這樣才能搭乘時更放心。
- 身為**需要趕早班的員工**，我希望能只看早上 7–9 點出發的行程，這樣才能快速找到符合上班時間的選擇。
- 身為**在意環保的使用者**，我希望能按減碳量排序，這樣才能選到對地球最友善的那一趟。

## 3. 功能範圍

### 已完成功能
- 綠色漸層 Header，顯示出發地、目的地、日期，並提供「返回搜尋」連結
- 行程卡片列表，每張卡片顯示：司機姓名、公司、評分、出發時間、車程時長、車型、價格、剩餘座位、可省 CO₂
- 排序列（4 種）：最早出發 / 最低價 / 最多減碳 / 最高評分；預設為「最早出發」，**排序必有一個選項被啟用，不可全部取消**
- 篩選結果筆數顯示（「找到 X 筆順路行程」）
- 有啟用篩選時顯示「清除篩選」按鈕
- 篩選結果為空時顯示空狀態畫面，並提供清除篩選按鈕
- 剩餘座位 1 席時以橘色標示，2 席以上以藍色標示
- 點擊行程卡片跳轉至行程詳情頁 `/results/[id]`

### 待製作
- 篩選條件（目前的早班 / 晚班 / 女性司機為暫時模擬版本，後續補充完整篩選項目）
- 依搜尋條件（起訖點、日期）實際過濾行程（目前顯示全部 4 筆 mock 資料，不管輸入什麼）
- 串接真實後端資料

## 4. 使用流程

**成功路徑：**
1. 使用者從首頁搜尋後，帶著 `?from=...&to=...&date=...` 進入 `/results`
2. 頁面顯示 Header（起訖點 + 日期）、篩選列、行程卡片列表
3. 預設排序為「最早出發」，篩選全開（顯示全部 4 筆）
4. 使用者點擊排序按鈕 → 列表即時重新排列
5. 使用者點擊篩選按鈕（可複選排序＋篩選）→ 列表即時更新，筆數同步更新
6. 使用者點擊某張行程卡片 → 跳轉至 `/results/[id]`

**例外情況：**
- 篩選後結果為 0 筆 → 顯示空狀態（搜尋圖示 + 「沒有符合條件的行程」+ 「試試調整篩選條件」提示 + 清除篩選按鈕）
- 直接進入 `/results`（沒有 query string）→ Header 顯示「出發地」/「目的地」預設文字，日期空白，仍正常顯示行程列表

## 5. 畫面與功能說明

**路由：** `/results`
**是否需要登入：** 否

### Header 區塊
- 綠色漸層背景
- 左上角「← 返回搜尋」連結（點擊回 `/`）
- 出發地（白色粗體）→ 目的地（白色半透明）以點線圖示連接
- 搜尋日期（白色細字）

### 篩選列（固定在 Header 下方）

**第一排：排序**（單選，預設「最早出發」）

| 按鈕 | 排序邏輯 |
|------|----------|
| 最早出發 | 出發時間升冪 |
| 最低價 | 價格升冪 |
| 最多減碳 | CO₂ 降冪 |
| 最高評分 | 評分降冪 |

啟用中：綠底白字；未啟用：灰底灰字

**第二排：篩選**（暫時模擬版本，待後續補充完整）

| 按鈕 | 篩選邏輯 |
|------|----------|
| 早班（07–09）| 出發時間 < 09:00 |
| 晚班（09+）| 出發時間 ≥ 09:00 |
| 女性司機 | ride-002、ride-004 |

啟用中：綠底框字（時間）/ 粉底框字（女性司機）；可單獨關閉（再點一次切回全部）

### 結果計數列
- 左側：「找到 **X** 筆順路行程」（X 以綠色粗體顯示）
- 右側：有篩選啟用時顯示「✕ 清除篩選」（灰字，hover 轉紅色）

### 行程卡片
每張卡片顯示：
- 司機頭像（姓氏文字，綠色漸層圓形）、姓名、公司、共乘次數、星等評分
- 出發地 → 目的地（點線圖示）、出發時間（綠色標籤）、車程時長
- 標籤列：省 X kg CO₂（綠）、車型（灰）、剩 X 座（藍 / 橘）

### 空狀態
- 灰色搜尋圖示
- 「沒有符合條件的行程」
- 「試試調整篩選條件」
- 「清除篩選」文字按鈕（綠色）

## 6. 資料說明

- **行程資料**：來自 `mockData.ts` 的 `mockRides`（4 筆），目前不依搜尋條件過濾
- **女性司機判斷**：寫死在 `results/page.tsx` 內的陣列 `femaleDriverIds: ["ride-002", "ride-004"]`，後續應改為由資料欄位判斷
- **搜尋條件**：從 URL query string（`from`、`to`、`date`）讀取，僅用於 Header 顯示，不影響資料過濾
- **無 localStorage 使用**：篩選與排序狀態僅存在頁面記憶體中，重新整理後重置

---

## 7. 設計規範

- 手機優先設計，最寬 448px
- 篩選列橫向可滑動（`overflow-x-auto`），不換行
- 頁面使用 `<Suspense>` 包覆內層元件（因使用 `useSearchParams`）
- 卡片 hover 狀態：邊框轉綠、陰影加深；點擊有輕微縮小動畫（`active:scale-[0.99]`）
