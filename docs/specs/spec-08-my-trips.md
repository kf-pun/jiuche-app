# 我的行程 功能規格書

**版本：** v1.0
**日期：** 2026-03-17
**狀態：** 已確認

---

## 1. 背景與目標

乘客預訂或司機發布行程後，需要一個地方集中查看所有共乘紀錄的狀態，並進行取消、聯絡司機、評價等後續動作。

**目標：**
- 提供即將出發與歷史紀錄兩個視角，讓使用者快速找到需要的行程
- 在 Header 展示累計減碳成就，強化 ESG 正向感受
- 提供對應狀態的快捷操作（確認中可取消 / 聯絡；完成可評價）

---

## 2. 使用者故事

- 身為**乘客**，我希望看到即將出發的行程清單，這樣才能確認出發時間與司機資訊。
- 身為**乘客**，我希望能聯絡司機或取消行程，這樣才能在計畫改變時做出應對。
- 身為**乘客**，我希望完成行程後能評價司機，這樣才能為社群品質做出貢獻。
- 身為**司機**，我希望查看哪些行程已有乘客預訂，這樣才能做好接送準備。
- 身為**使用者**，我希望看到我的累計減碳數字，這樣才能感受到長期環保貢獻。

## 3. 功能範圍

### 已完成功能
- AuthGuard 保護：未登入自動導向 `/auth/login`
- Header 累計減碳卡：顯示「完成共乘趟數」與「累計減碳 kg CO₂」
- 分頁切換：「即將出發」（confirmed + pending）/ 「歷史紀錄」（completed + cancelled）
- 空狀態：「即將出發」無資料時顯示插圖 + 「立即搜尋共乘」連結
- **行程卡 TripCard**：
  - 狀態 badge（已確認綠、待確認橘、已完成灰、已取消紅）
  - 角色 badge（司機藍 / 乘客紫）
  - 路線（出發地 + 目的地直線圖示）、時間
  - 底部：日期、司機姓名（乘客時）或乘客人數（司機時）、CO₂、費用
- **狀態對應操作按鈕：**
  - `confirmed`：「聯絡司機」+ 「取消行程」（按鈕為視覺展示，無實際邏輯）
  - `completed` + 乘客：「評價此行程」→ `/trips/{id}/review`
  - `pending` / `cancelled`：無操作按鈕

### 待製作
- 「聯絡司機」目前點擊無反應（無 IM 或電話功能）
- 「取消行程」目前點擊無反應（不更新行程狀態）
- 已完成的司機角色行程無操作按鈕（未來可加「查看乘客評價」）
- 歷史紀錄無空狀態處理（若 history 為空，目前渲染空 div）

## 4. 使用流程

**進入頁面：**
1. 已登入使用者點擊 BottomNav 或其他連結進入 `/trips`
2. 預設顯示「即將出發」分頁

**查看行程：**
1. 切換分頁 → 顯示對應行程清單
2. 點擊「評價此行程」→ 進入 `/trips/{id}/review`

**即將出發為空：**
1. 顯示插圖 + 「尚無即將出發的行程」
2. 點擊「立即搜尋共乘」→ 回到首頁 `/`

**例外：未登入**
1. AuthGuard 攔截，記錄 `jiuche_redirect = /trips` 至 sessionStorage
2. 跳轉至 `/auth/login`，登入後跳回 `/trips`

## 5. 畫面與功能說明

### 我的行程頁
- **路由：** `/trips`
- **是否需要登入：** 是（AuthGuard 保護）
- **Header：** 綠色漸層，標題「我的行程」；底部白色半透明卡片顯示累計減碳與完成趟數
- **分頁列：** 白底，下底線指示選中分頁；即將出發 / 歷史紀錄各顯示筆數

**行程卡欄位說明：**

| 欄位 | 說明 |
|------|------|
| 狀態 badge | 已確認（綠）/ 待確認（橘）/ 已完成（灰）/ 已取消（紅） |
| 角色 badge | 司機（藍）/ 乘客（紫）|
| 訂單編號 | 右上角小字 |
| 路線 | 出發地（綠點）→ 目的地（深綠點）+ 出發時間 |
| 日期 | 格式：`3月17日（一）` |
| 司機 / 乘客資訊 | 乘客視角：司機名 + 頭像首字；司機視角：「乘客 N 人」|
| CO₂ | `-X.X kg CO₂`（綠色）|
| 費用 | `NT$XXX` |

**操作按鈕（依狀態）：**

| 狀態 | 角色 | 按鈕 |
|------|------|------|
| confirmed | 乘客 | 聯絡司機、取消行程 |
| completed | 乘客 | 評價此行程 |
| pending / cancelled | 任何 | 無 |
| 任何 | 司機 | 無（待製作）|

## 6. 資料說明

- **行程資料**：來自頁面內 `mockTrips`（5 筆），**與 `mockData.ts` 無關，為獨立 mock**
- 5 筆涵蓋：confirmed×1、pending×1、completed×2（司機+乘客各一）、cancelled×1
- 累計減碳：`mockTrips.filter(completed).reduce(co2Saved)` = 3.0 kg CO₂
- 完成趟數：`history.filter(completed).length` = 2 趟
- 行程資料欄位：`id, type, driverName?, passengerCount?, from, to, date, time, price, co2Saved, status, bookingId`
