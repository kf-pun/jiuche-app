# 儲值 功能規格書

**版本：** v1.1
**日期：** 2026-03-18
**狀態：** 已確認

---

## 1. 背景與目標

使用者在錢包餘額不足時，需要一個快速、直觀的儲值入口，才能順利完成共乘預訂。儲值完成後應即時反映新餘額，並提供交易明細供使用者確認。

**目標：**
- 讓使用者在 3 步以內完成儲值（選金額 → 選付款方式 → 確認）
- 即時更新錢包餘額，確保儲值後立即可用
- 提供清楚的交易明細，降低「有沒有成功？」的疑慮

---

## 2. 使用者故事

- 身為**乘客**，我希望快速選擇常用儲值金額，這樣才能不用每次手動輸入。
- 身為**使用者**，我希望看到儲值後的預覽餘額，這樣才能確認金額正確再送出。
- 身為**使用者**，我希望選擇慣用的付款方式，這樣才能用最方便的管道完成付款。
- 身為**使用者**，我希望儲值完成後看到交易明細，這樣才能留存紀錄以備查詢。

## 3. 功能範圍

### 已完成功能

**儲值頁 `/wallet/topup`：**
- Header 顯示目前餘額
- 6 個預設金額快選按鈕：NT$100 / 300 / 500 / 1,000 / 2,000 / 3,000
- 自訂金額輸入框（NT$ 前綴，範圍 100～10,000）
- 金額驗證：低於 100 顯示「最低儲值金額為 NT$ 100」；超過 10,000 顯示「單次儲值上限為 NT$ 10,000」
- 儲值後餘額預覽（金額 ≥ 100 時顯示）
- 4 種付款方式選擇：信用卡 / LINE Pay / ATM 轉帳 / 超商條碼
- 確認儲值按鈕（金額不足時 disabled + 半透明）
- **[S4-2 新增]** 按鈕點擊後：呼叫 `createTopup()` Server Action → 成功後 `refreshUser()` → 跳轉成功頁；失敗時顯示紅色錯誤提示
- 未登入時顯示「請先登入」+ 登入連結

**儲值成功頁 `/wallet/topup/success`：**
- 綠色勾勾動畫（scale + opacity）
- 大字顯示儲值金額
- 交易明細卡：交易編號、儲值金額、付款方式、交易時間
- 更新後餘額卡（綠色漸層底）
- 操作按鈕：「返回錢包」（→ `/wallet`）、「去搜尋共乘」（→ `/`）

### 待製作
- 付款方式目前為純視覺選擇，無實際串接金流（正式需串接各支付閘道）
- 超商條碼應顯示條碼圖片（正式版）
- ATM 轉帳應顯示虛擬帳號（正式版）

## 4. 使用流程

**成功路徑：**
1. 在錢包頁點擊「儲值」→ 進入 `/wallet/topup`
2. 點擊預設金額（或輸入自訂金額）
3. 選擇付款方式（預設：信用卡）
4. 確認儲值後餘額預覽無誤
5. 點擊「確認儲值」按鈕，顯示 Spinner 動畫 1.5 秒
6. `addBalance(amount)` 執行，localStorage 餘額更新
7. 自動跳轉 `/wallet/topup/success?amount={金額}&method={方式}`
8. 看到成功動畫 + 交易明細 + 更新後餘額

**例外：金額不合規**
- 金額 < 100：錯誤訊息「最低儲值金額為 NT$ 100」，按鈕保持 disabled
- 金額 > 10,000：錯誤訊息「單次儲值上限為 NT$ 10,000」，按鈕保持 disabled
- 清空金額後按鈕保持 disabled（`finalAmount < 100` 條件控制）

**例外：未登入**
- `/wallet/topup` 頁面檢查 `isLoggedIn`，未登入時顯示「請先登入」+ 前往登入連結
- 注意：此頁未使用 AuthGuard，改為頁面內自行判斷

## 5. 畫面與功能說明

### 儲值頁
- **路由：** `/wallet/topup`
- **是否需要登入：** 是（頁面內判斷，非 AuthGuard）

**Header（綠色漸層）：**
- 返回「← 返回錢包」連結（→ `/wallet`）
- 標題「儲值」+ 副標「目前餘額 NT$ {balance}」

**金額選擇卡（白色圓角卡）：**
- 3×2 格預設金額按鈕，選中者變綠色背景
- 自訂金額輸入框（帶 NT$ 前綴，type=number，placeholder: 100 ～ 10,000）
- 聚焦或有值時輸入框邊框轉綠色
- 錯誤訊息紅字顯示於輸入框下方
- 儲值後餘額預覽：`目前餘額 + 選擇金額`（金額 ≥ 100 才顯示，綠色底）

**付款方式卡（白色圓角卡）：**
- 4 個選項縱向排列，每項含：彩色圖示、名稱、說明文字、Radio 圓圈
- 選中者：綠色邊框 + 淺綠底 + Radio 填滿綠色

**確認按鈕：**
- 綠色漸層，文字顯示「確認儲值 NT$ {金額}」
- 金額未達 100 時：`opacity-50 cursor-not-allowed`（disabled）
- 處理中：白色 Spinner + 「處理中...」文字

**免責聲明：**
- 按鈕下方小字：「儲值後不支援退款，請確認金額後再送出」

---

### 儲值成功頁
- **路由：** `/wallet/topup/success?amount=&method=`
- **是否需要登入：** 否（但餘額顯示依賴 authContext）

**動畫區：**
- 綠色漸層圓圈（w-24 h-24）+ 白色勾勾，100ms 後觸發（scale 50→100，delay 300ms）
- 「儲值成功！」標題 + 大字金額 `NT$ {amount}`（emerald 綠色），delay 200ms

**交易明細卡（白色圓角卡，delay 300ms）：**

| 欄位 | 內容 |
|------|------|
| 交易編號 | `TX` + 8 位隨機數字 |
| 儲值金額 | `NT$ {amount}` |
| 付款方式 | 對應中文標籤 |
| 交易時間 | 當前時間（月/日 時:分） |

**更新後餘額卡（綠色漸層底，delay 300ms）：**
- 左：「更新後餘額」小標 + 大字 `NT$ {user.balance}`（來自 authContext，已含本次儲值）
- 右：白色半透明錢包圖示

**操作按鈕（delay 300ms）：**
- 「返回錢包」— 綠色漸層主按鈕
- 「去搜尋共乘」— 白底灰字次要按鈕

## 6. 資料說明

- **儲值流程：** 呼叫 `createTopup(amount, method)` Server Action（`src/actions/wallet.ts`）：①寫入 `wallet_transactions`（type: topup）②更新 `users.balance`；成功後呼叫 `refreshUser()` 同步前端狀態
- **付款方式選擇：** 純前端狀態（useState），存入 wallet_transactions.description（如「儲值（信用卡）」）
- **交易編號：** 成功頁以 `useState(() => "TX" + random)` 前端產生，正式版應從 DB 讀取 wallet_transactions.id
- **交易時間：** `new Date().toLocaleString("zh-TW")`，顯示當前時間
- 儲值完成後 wallet 頁交易紀錄會即時反映（從 DB 載入）
