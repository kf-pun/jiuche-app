# 預訂確認 功能規格書

**版本：** v1.0
**日期：** 2026-03-17
**狀態：** 已確認

---

## 1. 背景與目標

乘客在行程詳情頁點擊「立即預訂」後，需要一個明確的付款確認步驟，避免誤操作。同時這是扣款的關鍵時刻，需要清楚呈現費用明細、錢包餘額與 ESG 減碳資訊。

**目標：**
- 讓乘客在付款前完整確認行程資訊與費用
- 餘額不足時即時提示並引導儲值，避免流程中斷
- 透過 ESG 減碳提示強化環保行動的正向感受

---

## 2. 使用者故事

- 身為**乘客**，我希望在付款前看到行程摘要與費用明細，這樣才能確認沒有搭錯車或金額錯誤。
- 身為**乘客**，我希望看到付款後的錢包剩餘金額，這樣才能判斷是否夠用。
- 身為**錢包餘額不足的乘客**，我希望系統提示我去儲值，這樣才能完成預訂而不必重頭再來。
- 身為**企業員工**，我希望看到這趟共乘的 CO₂ 減排估算，這樣才能感受到環保貢獻。

## 3. 功能範圍

### 已完成功能
- 顯示行程摘要（司機頭像/姓名/公司、出發地、目的地、時間、集合地點）
- 費用明細（每人費用 × 乘客人數、服務費 NT$0、總計）
- 揪車錢包付款區塊：
  - 餘額充足：顯示現有餘額與付款後剩餘金額
  - 餘額不足：紅色警示 + 「立即儲值」按鈕（連結 `/wallet/topup`）
- ESG 減碳提示卡（預估減少 X kg CO₂）
- 「確認付款」按鈕：按下後 1.2 秒 loading 動畫，再執行 `deductBalance()` 並跳轉至成功頁
- 付款按鈕 disabled 條件：餘額不足 / 付款中 / 未登入
- 返回行程詳情的連結

### 待製作
- 座位數選擇（目前從行程詳情頁帶入，固定為 1 人，若使用者想訂 2 席，目前無法操作）

## 4. 使用流程

**成功路徑：**
1. 乘客在行程詳情頁點擊「立即預訂」
2. 帶著 `rideId` 與 `seats` 參數進入 `/booking/confirm`
3. 看到行程摘要、費用明細、錢包餘額
4. 確認無誤，點擊「確認付款 NT$ {金額}」
5. 按鈕進入 loading 狀態（1.2 秒）
6. 系統執行 `deductBalance(total)`
7. 自動跳轉至 `/booking/success`（帶入行程資訊參數）

**例外：餘額不足**
1. 系統偵測 `user.balance < total`
2. 錢包付款區塊變為紅色，顯示「餘額不足，請先儲值」
3. 出現「立即儲值」按鈕，連結至 `/wallet/topup`
4. 「確認付款」按鈕 disabled（灰色、無法點擊）

**例外：找不到行程**
1. `rideId` 無對應資料（URL 被竄改或 mock 資料不存在）
2. 顯示「找不到行程資訊」提示
3. 顯示「返回首頁」連結

## 5. 畫面與功能說明

### 確認付款頁
- **路由：** `/booking/confirm?rideId={id}&seats={n}`
- **是否需要登入：** 否（但未登入時付款按鈕 disabled）
- **畫面元素：**
  - Header：綠色漸層，標題「確認付款」，副標「請確認以下行程與金額」
  - 左上角「← 返回行程詳情」連結（回到 `/results/{rideId}`）
  - **行程摘要卡**：司機頭像（emoji）/ 姓名 / 公司 / 車型、出發地+時間 / 目的地（直線圖示）、集合地點
  - **費用明細卡**：每人費用、乘客人數、服務費（NT$0）、總計（綠色粗體）
  - **錢包付款卡**：
    - 餘額充足：白底綠框，顯示「目前餘額 NT$ X，付款後剩 NT$ Y」
    - 餘額不足：紅底紅框，顯示「餘額不足，請先儲值」＋「立即儲值」按鈕
  - **ESG 提示卡**：淡綠底，「這趟共乘預估減少 X kg CO₂，感謝您的環保行動！」
  - **確認付款按鈕**：綠色漸層，顯示「確認付款 NT$ {total}」；按下後顯示 spinner + 「付款中...」

## 6. 資料說明

- **行程資料**：來自 `mockData.ts`，透過 `getRideById(rideId)` 取得
- **使用者資料**：來自 `authContext`（`user.balance`）
- **扣款**：呼叫 `authContext.deductBalance(total)`，結果更新至 `authContext` 並持久化至 `localStorage`（key: `jiuche_user`）
- **URL 參數**：
  - `rideId`：行程 ID（如 `ride-001`）
  - `seats`：乘客人數（整數，預設 1）
- **成功頁傳遞參數**（URL query）：`rideId`, `driverName`, `from`, `to`, `time`, `co2`, `price`

- 手機優先，最寬 448px，底部保留 `pb-20` 避免被 BottomNav 遮住
- Header：`bg-gradient-to-br from-green-600 to-emerald-500 px-5 pt-12 pb-6`

- 頁面使用 `<Suspense>` 包裹（因使用 `useSearchParams`）
