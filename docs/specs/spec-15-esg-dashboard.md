# ESG 儀表板 功能規格書

**版本：** v1.0
**日期：** 2026-03-17
**狀態：** 已完成

---

## 1. 背景與目標

揪車的核心差異化在於 ESG 減碳價值主張。儀表板讓個人能看到自己的減碳成果，讓企業能掌握整體共乘貢獻，強化員工持續使用的動機，也支援企業對外的 ESG 報告需求。

### 目標
1. 讓個人直觀感受自己的減碳貢獻（數字、趨勢、換算）
2. 透過成就勳章機制激勵持續共乘
3. 讓企業管理者看到全公司共乘排行，支援 ESG 報告匯出

---

## 2. 使用者故事

- 身為**員工**，我希望看到自己這個月減少了多少碳，這樣才能感受到共乘對環境的實際貢獻
- 身為**環保意識強的使用者**，我希望看到成就勳章與進度，這樣才有動力繼續共乘
- 身為**企業 ESG 負責人**，我希望看到全公司的共乘減碳統計與排行榜，這樣才能用於永續報告

---

## 3. 功能範圍

### 已完成功能
- AuthGuard 保護（未登入跳至登入頁）
- **Header**：標題「ESG 減碳」、副標語、主數字卡（累計減碳 kg、距「減碳達人」勳章進度條）
- **統計列**（3 格）：共乘次數、等同種樹（棵）、少開車（km）
- **個人 / 企業 分頁切換**（Tab）
- **個人分頁：**
  - 月度減碳趨勢（6 個月 CSS 條形圖，最新月份綠色，其餘淡綠）
  - 環比提示（本月比上月少排放 X%）
  - 減碳換算：飛機單程比例、節省用電（度）、減少塑膠袋（個）
  - 成就勳章（6 枚，3×2 格），已解鎖綠色顯示，未解鎖灰階 + 進度條
  - SDG 貢獻卡（SDG 11 / 13 / 17）
- **企業分頁：**
  - 企業總覽卡（本月總減碳 kg、共乘趟次、參與員工數）
  - 減碳排行榜（5 人，前 3 名金銀銅牌，自己高亮綠色）
  - ESG 報告匯出區塊（「匯出 PDF 報告」按鈕，標注「B2B 企業版專屬功能」）

### 待製作
- 「匯出 PDF 報告」按鈕目前無實際功能（外觀展示）
- 月度趨勢、排行榜皆為假資料，未與使用者行程紀錄計算
- 成就勳章中「連續共乘 streak」與「排行榜 rank」的進度為假資料（streak: 3, rank: 4 固定）

---

## 4. 使用流程

1. 點擊底部導覽列「ESG」→ AuthGuard 確認已登入
2. 進入 `/esg`，預設顯示「個人數據」分頁
3. 查看累計減碳、統計列、月度趨勢、成就勳章
4. 點擊「企業排行」Tab → 切換至企業分頁
5. 查看公司總覽與排行榜，點擊「匯出 PDF 報告」（目前無動作）

## 5. 畫面與功能說明

**路由：** `/esg`
**需要登入：** 是（AuthGuard 保護）

**Header**（綠色漸層）
- 「ESG 減碳」標題 ＋ 副標「你的每次共乘，都是對地球的承諾」
- 主數字卡（白色半透明圓角卡 `bg-white/15 rounded-3xl`）：
  - 「累計減少碳排放」→ `{co2Total} kg CO₂`（大字）
  - 白色進度條：`co2Total / 50 * 100%`（50 kg 為「減碳達人」門檻）
  - 下方顯示距勳章還差幾 kg

**統計列**（`-mt-3` 壓在 Header 下，3 格白色卡片）
- 🚗 共乘次數（趟）
- 🌳 等同種樹（`co2Total / 21.77` 棵）
- ⛽ 少開車（`co2Total / 0.21` km）

**Tab 切換列**（個人數據 / 企業排行）

**個人分頁內容：**
- 月度趨勢卡：6 個月條形圖（最新月份綠色漸層，其餘淡綠）＋環比提示
- 減碳換算卡：飛機、電費、塑膠袋三項對比
- 成就勳章卡（3×2 格）：

| 勳章 | 條件 | 解鎖判斷 |
|------|------|----------|
| 🌱 初次綠行 | 完成 1 趟共乘 | `rides >= 1` |
| 🌿 綠色通勤者 | 累計減碳 20 kg | `co2 >= 20` |
| 🌳 減碳達人 | 累計減碳 50 kg | `co2 >= 50` |
| ⭐ 五星司機 | 完成 30 趟 | `rides >= 30` |
| 🔥 連續共乘 | 連續 5 天 | `streak >= 5` |
| 🏆 ESG 領袖 | 排行前 3 名 | `rank <= 3` |

- SDG 卡（藍色漸層）：SDG 11 永續城市 / SDG 13 氣候行動 / SDG 17 夥伴關係

**企業分頁內容：**
- 企業總覽卡（emerald → teal 漸層）：台積電・本月 2,847 kg CO₂、312 趟、87 員工
- 排行榜卡：5 人，前 3 名用 🥇🥈🥉，第 4 名「你」高亮綠底
- ESG 報告卡：圖示 + 說明 + 「匯出 PDF 報告」按鈕（外觀展示，B2B 企業版）

## 6. 資料說明

| 項目 | 說明 |
|------|------|
| `co2Total` | 來自 `authContext` `user.co2Total`，DEFAULT_USER 預設 28.4 kg |
| `totalRides` | 來自 `authContext` `user.totalRides`，DEFAULT_USER 假資料 |
| `monthlyData` | 頁面內部假資料（6 個月固定數字） |
| `leaderboard` | 頁面內部假資料（5 筆固定），第 4 筆 `isMe: true` |
| `streak` | 假資料固定 3 天 |
| 企業總覽數字 | 假資料（2,847 kg、312 趟、87 人） |
