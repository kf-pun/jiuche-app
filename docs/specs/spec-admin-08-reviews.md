# 後台評價管理 功能規格書

**版本：** v1.0
**日期：** 2026-03-18
**狀態：** 已確認

---

## 1. 背景與目標
- 管理員需要對平台上的不當評價（惡意灌水、人身攻擊）進行刪除，維護評分公正性
- 目標：提供評價列表瀏覽、篩選搜尋、刪除不當評價並自動重算司機平均分

## 2. 使用者故事
- 身為管理員，我希望用星等和日期篩選評價，這樣才能快速找出低分異常評價
- 身為管理員，我希望刪除不當評價，這樣才能維護平台評分可信度
- 身為管理員，我希望刪除後系統自動重算司機平均分，這樣才能確保司機分數正確

## 3. 功能範圍

### 已完成功能
- 無

### 待製作

- 刪除後重算司機平均評分

## 4. 使用流程

**查看評價：**
1. 管理員進入 `/admin/reviews`
2. 可用星等（1～5 星）和日期範圍篩選
3. 可搜尋乘客姓名或司機姓名

**刪除評價：**
1. 點擊某筆評價右側「刪除」（紅色）
2. Modal 確認：「確認刪除此評價？刪除後將重新計算 [司機姓名] 的平均評分。」
3. 確認 → 刪除 `reviews` 表該筆記錄 → 重算司機平均分（`AVG(rating)` from reviews where driver_id）→ 更新 `users.rating`
4. 成功：toast 綠色，列表刷新

## 5. 畫面與功能說明

### 評價列表（`/admin/reviews`）
- **頁面標題：** 評價管理

**工具列：**
- 搜尋欄（乘客或司機姓名，debounce 500ms）
- 星等篩選 select：全部 / 1星 / 2星 / 3星 / 4星 / 5星
- 日期範圍（起～迄，type=date）

**表格欄位：**

| 欄位 | 說明 |
|------|------|
| 乘客 | 頭像縮寫 + 姓名，可點擊連到 `/admin/users/[id]` |
| 司機 | 頭像縮寫 + 姓名，可點擊連到 `/admin/users/[id]` |
| 星等 | 填滿星圖示（黃色）× N |
| 評語 | 截取 50 字，超過顯示「…」 |
| 快速標籤 | 最多顯示 3 個標籤 |
| 建立時間 | YYYY/MM/DD |
| 操作 | 「刪除」紅色文字按鈕 |

- **排序：** 預設依「建立時間」降冪
- **分頁：** 每頁 20 筆
- **空狀態：** 「目前沒有符合條件的評價」

### 刪除確認 Modal
- 紅色警示圖示
- 標題：「確認刪除此評價？」
- 說明：「刪除後將重新計算 [司機姓名] 的平均評分，此操作無法復原。」
- 按鈕：「取消」（灰）、「確認刪除」（紅）

## 6. 資料說明
- 讀取：`reviews` join `bookings` join `rides`（取司機 user_id）join `users` × 2（乘客、司機）
- 刪除後重算：`SELECT AVG(rating) FROM reviews WHERE driver_id = ?`（driver_id 從 rides 取得）→ `UPDATE users SET rating = ?`

**Server Actions（`src/actions/admin/reviews.ts`）：**
```ts
getAdminReviews(params)         // 列表（搜尋/篩選/分頁）
deleteReview(reviewId)          // 刪除 + 重算司機評分
```

## 7. 設計規範
- 同後台其他頁規範（`bg-white rounded-xl shadow-sm`）
- 星等顯示：`text-yellow-400`，空星 `text-gray-200`
- 刪除按鈕：`text-red-600 hover:text-red-800`（文字按鈕，不加背景）

## 8. 備註
- 刪除為硬刪除（直接移除記錄），無軟刪除
- 若司機沒有任何評價，`users.rating` 更新為 `null`（前台顯示「尚無評分」）
