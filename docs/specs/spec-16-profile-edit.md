# 編輯個人資料 功能規格書

**版本：** v1.0
**日期：** 2026-03-17
**狀態：** 已完成

---

## 1. 背景與目標

使用者需要能修改已填寫的姓名、公司，以及切換司機身份與車輛資訊。本頁與「註冊頁」邏輯相近，但資料預填自現有帳號，修改後即時同步至 `authContext`。

### 目標
1. 讓使用者能修改姓名、公司
2. 讓乘客能開啟司機身份（或司機關閉身份）並更新車輛資訊
3. 儲存後即時反映至個人資料頁

---

## 2. 使用者故事

- 身為**換工作的使用者**，我希望能修改公司名稱，這樣才能正確媒合新公司的同事
- 身為**剛買車的員工**，我希望能在個人資料開啟司機模式並填入車輛資訊，這樣才能開始發布共乘

---

## 3. 功能範圍

### 已完成功能
- Header：「← 返回個人資料」連結 + 標題「編輯資料」
- 未登入保護（顯示「請先登入」+ 「前往登入」連結，頁面內判斷，非 AuthGuard）
- 基本資料卡：姓名（必填）、公司（必填），預填自 `user`
- 司機設定卡：切換開關（預填自 `user.isDriver`），展開後顯示車型、車牌、車身顏色（6 種色票）
- 姓名或公司為空時，「儲存變更」按鈕 disabled
- 儲存流程：模擬 0.9 秒 → 呼叫 `updateUser()` → 按鈕切換為「✓ 已儲存！」→ 0.8 秒後自動跳回 `/profile`

### 待製作
- 無欄位驗證錯誤訊息（目前僅靠 disabled 阻止送出，無紅字提示）
- 手機號碼欄位未顯示（不支援修改）

---

## 4. 使用流程

1. 從 `/profile` 點擊編輯按鈕或「個人資料」選單 → 進入 `/profile/edit`
2. 修改姓名 / 公司 / 司機設定 / 車輛資訊
3. 點擊「儲存變更」
4. 旋轉動畫（0.9 秒）→ 「✓ 已儲存！」→ 0.8 秒後自動跳回 `/profile`

### 例外
- 姓名或公司為空：按鈕 disabled，無法送出
- 未登入：顯示「請先登入」＋「前往登入」連結

---

## 5. 畫面與功能說明

**路由：** `/profile/edit`
**需要登入：** 是（頁面內判斷 `isLoggedIn`，未登入顯示提示而非 AuthGuard 跳轉）

**Header**（綠色漸層）
- 「← 返回個人資料」連結（回 `/profile`）
- 標題「編輯資料」

**基本資料卡片**（白色圓角卡）
- 區塊標題「基本資料」
- 姓名欄位（預填 `user.name`）
- 公司/機構欄位（預填 `user.company`）

**司機設定卡片**（白色圓角卡）
- 標題「司機設定」＋ 副標「開啟後可發布共乘行程」
- 切換開關（預填 `user.isDriver`）
- 開啟後展開（帶分隔線）：
  - 車型（預填 `user.carModel`）
  - 車牌號碼（預填 `user.carPlate`）
  - 車身顏色色票（預填 `user.carColor`，6 種：白/銀/黑/灰/藍/紅）

**儲存按鈕三種狀態：**

| 狀態 | 樣式 | 說明 |
|------|------|------|
| 一般 | 綠色漸層「儲存變更」 | 姓名與公司均非空 |
| disabled | 半透明 | 姓名或公司為空 |
| 儲存中 | 旋轉圖示 + 「儲存中...」 | 送出後 0.9 秒 |
| 已儲存 | 淡綠底 + 打勾圖示 + 「已儲存！」 | 成功後 0.8 秒內 |

---

## 6. 資料說明

| 項目 | 說明 |
|------|------|
| 初始值 | 從 `authContext` 的 `user` 物件預填 |
| 儲存 | 呼叫 `updateUser(partial)` 更新 `authContext` 與 `localStorage` |
| `avatar` | 儲存時取 `name.trim()[0]` 自動更新頭像首字 |
| 手機號碼 | 不顯示、不可修改 |

---

## 7. 設計規範

- Header：`bg-gradient-to-br from-green-600 to-emerald-500 px-5 pt-12 pb-6`
- 輸入框：`bg-gray-50 rounded-xl border border-gray-100 focus:border-green-400`
- 切換開關：與註冊頁相同（`w-12 h-6`，`transition-colors`）
- 按鈕已儲存樣式：`bg-green-100 text-green-700`（非漸層）
- 按鈕 active 動畫：`active:scale-95`

---

## 8. 備註

- 欄位修改儲存後即時反映在 `localStorage`，重新整理後保留。
- 手機號碼欄位未顯示，正式上線需另做「變更手機號」流程（含新 OTP 驗證）。
- 若司機關閉「司機設定」後儲存，`carModel`、`carPlate`、`carColor` 皆清空為空字串。
