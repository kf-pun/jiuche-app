## 1. 背景與目標

目前起訖點輸入只有文字自動完成，使用者必須準確輸入地名才能搜尋，對不熟悉地址的人不友善，也無法得知行車距離與預計時間。此外，原有車費計算缺乏法規依據與透明度。

**目標：**
- 透過地圖選點與 GPS 定位，讓起訖點輸入零打字即可完成
- 自動計算路線距離與行車時間，提升行程資訊透明度
- 建立合法合規的費用架構：司機收油資分攤、平台向乘客收服務費、企業包月免員工服務費

---

## 2. 使用者故事

- 身為**乘客**，我希望點一下「定位」就能自動填入目前位置，這樣才能省去手動輸入出發地的麻煩。
- 身為**乘客**，我希望在地圖上點選目的地，這樣才能精準選到沒有固定地名的地點（如公司大樓側門）。
- 身為**乘客**，我希望在行程詳情看到路線地圖與行車時間，這樣才能評估是否值得搭乘。
- 身為**司機**，我希望發布行程時系統自動建議合理油資分攤上限，確保收費合法又省事。
- 身為**企業 HR**，我希望員工搭乘無需另付服務費，這樣才能作為員工福利推廣共乘。

## 4. 費用架構

### 法規說明
依台灣法規，共乘費用不得超過「合理分攤油資 + 過路費」。司機不得以共乘營利，只能收回成本。平台可另向乘客收取「媒合服務費」。

### 油資上限計算公式

```
油資上限（每位乘客）= (距離 km × 車型油耗 × 當週油價) ÷ 乘客數 + 過路費分攤
當週油價：每週四自動從台灣中油（CPC）官網抓取，依車型類別預設油號讀取
車型油耗：依司機車輛資料查官方油耗表（見下方）
範例：10km，Toyota Camry（95無鉛），油價 $32.5/L，2 人共乘
      → (10 × 0.095 × 32.5) ÷ 2 = $15.4 → 取整數 $15
```

**車型油耗對照表（市區修正值 + 預設油號，內建於系統）**

| 車型類別 | 代表車款 | 市區油耗（L/km） | 預設油號 |
|---------|---------|----------------|---------|
| 小型轎車 | Yaris / Fit / Vios | 0.068 | 95 無鉛 |
| 中型轎車 | Camry / Altis / Mazda 3 | 0.095 | 95 無鉛 |
| 大型轎車 | Accord / Passat | 0.110 | 98 無鉛 |
| SUV（小） | HR-V / Kicks | 0.095 | 95 無鉛 |
| SUV（中） | RAV4 / CRV / Tiguan | 0.109 | 95 無鉛 |
| SUV（大） | Highlander / Kodiaq | 0.130 | 98 無鉛 |
| MPV | Sienna / Carnival | 0.127 | 95 無鉛 |
| 電動車 | Tesla / BYD | 0（不計油耗） | N/A |

> 資料來源：交通部能源局車輛油耗資訊網（ecocar.artc.org.tw），取官方值 × 1.15 市區修正係數。
> 司機在「個人資料 → 車輛設定」選擇車型類別，系統自動帶入油耗與油號，均不開放手動修改。
> 油號依車型類別固定預設，避免司機選高油號多報油資（每趟差額約 $2–7）。

### 費用角色分配

**平台服務費分級（方案 B — 依距離）**

| 距離 | 服務費 | 適用情境 |
|------|--------|---------|
| 0–10 km | $10 | 市區短程 |
| 11–30 km | $15 | 一般通勤 |
| 31 km 以上 | $20 | 長途跨縣市 |

| 角色 | 散客模式 | 企業員工模式 |
|------|---------|------------|
| **乘客付** | 油資分攤 + 平台服務費（依距離分級） | 油資分攤（無服務費） |
| **司機收** | 油資分攤全額（無扣除） | 油資分攤全額（無扣除） |
| **平台收** | 乘客服務費（$10/$15/$20） | 企業月費（涵蓋員工服務費） |

> 服務費金額後台可調整；企業員工判斷依 `users.company` 對應 `companies.subscription_active = true`。

### 企業判斷邏輯
- 乘客的 `users.company` 對應到 `companies` 表中 `subscription_active = true` 的企業 → 免服務費
- 否則視為散客 → 收服務費 $15

## 5. 使用流程

### 5-1 GPS 定位（首頁 / 發布行程）

1. 使用者點擊出發地欄位旁的「📍 定位」按鈕
2. 瀏覽器彈出定位授權請求
3. **授權成功**：呼叫 Geocoding API 將座標轉為地址，自動填入出發地欄位
4. **授權拒絕 / 逾時**：顯示提示「無法取得位置，請手動輸入」，欄位維持空白

### 5-2 地圖選點 Modal

1. 使用者點擊起點或終點欄位右側的「🗺 地圖」按鈕
2. 全螢幕 Modal 開啟，頂部有搜尋框（複用 Places autocomplete），地圖佔據中間
3. 搜尋地點後地圖自動跳到該位置並落下大頭針；也可直接點擊地圖任意位置
4. 底部顯示反查後的地址文字
5. 點擊「確認」→ Modal 關閉，地址與座標帶回欄位
6. 點擊「取消」→ Modal 關閉，欄位不變

### 5-3 路線預覽（行程詳情頁）

1. 頁面載入，取得起訖點座標
2. 呼叫 Directions API 計算路線（開車模式）
3. 顯示地圖卡片：藍線路線 + 起點綠色大頭針 + 終點紅色大頭針
4. 卡片下方顯示距離（km）與預計行車時間
5. **無 API Key** 或**舊行程（無座標）**：隱藏地圖卡片，向下相容

### 5-4 車費設定（發布共乘頁）

1. 司機填入起訖點後（含座標），自動呼叫 Directions API 取得距離
2. 系統依「司機車型油耗 × 油價 ÷ 乘客數」計算法定油資上限
3. 顯示提示列：「法定上限 $XX（依 Xkm × 車型油耗估算）｜服務費 $X（由乘客另付）」
4. 票價欄位預填上限值，司機可調低但**不得超過上限**（超過時欄位變紅並阻擋送出）
5. 送出時一併寫入 `distance_km`、`duration_minutes`、`fare_limit`、座標欄位

### 5-5 預訂確認頁費用拆分

```
散客（例：15km）：
  油資分攤       $XX
  平台服務費     $15（11–30km）
  ──────────────────
  合計           $XX

企業員工：
  油資分攤       $XX
  服務費         $0（企業包月，顯示「企業方案」）
  ──────────────────
  合計           $XX
```

### 預訂確認（`/booking/confirm`）
- 費用區塊拆分為「油資分攤」+「平台服務費」兩行
- 企業員工：服務費顯示 $0 並標注「企業方案」
- **需要登入**：是

### 行程詳情（`/results/[id]`）
- 司機資訊卡片下方新增「路線地圖」卡片（高度 200px，`rounded-xl overflow-hidden shadow-sm`）
- 地圖：藍線路線 + 起終點大頭針
- 卡片下方：🛣 `X km` ｜ 🕐 `約 Y 分鐘`（`text-sm text-gray-500`）
- 載入中：骨架屏；無座標：隱藏卡片
- **需要登入**：否

## 7. 資料說明

### DB 新增欄位（`rides` 表）

| 欄位 | 型別 | 說明 |
|------|------|------|
| `origin_lat` | NUMERIC(10,7) | 起點緯度（可為 NULL） |
| `origin_lng` | NUMERIC(10,7) | 起點經度（可為 NULL） |
| `destination_lat` | NUMERIC(10,7) | 終點緯度（可為 NULL） |
| `destination_lng` | NUMERIC(10,7) | 終點經度（可為 NULL） |
| `distance_km` | NUMERIC(6,2) | 路線距離公里數（可為 NULL） |
| `duration_minutes` | INTEGER | 預計行車分鐘數（可為 NULL） |
| `fare_limit` | INTEGER | 法定油資上限（可為 NULL） |

### DB 新增欄位（`bookings` 表）

| 欄位 | 型別 | 說明 |
|------|------|------|
| `service_fee` | INTEGER | 平台服務費（$10/$15/$20 依距離分級，企業員工 0） |

### DB 新增欄位（`companies` 表）

| 欄位 | 型別 | 說明 |
|------|------|------|
| `subscription_active` | BOOLEAN | 企業訂閱是否有效（預設 false） |
| `subscription_expires_at` | TIMESTAMPTZ | 訂閱到期時間（可為 NULL） |

### 新增表（`system_config`）

| 欄位 | 型別 | 說明 |
|------|------|------|
| `key` | TEXT PRIMARY KEY | 設定鍵（如 `fuel_price_92`、`fuel_price_95`、`fuel_price_98`） |
| `value` | TEXT | 設定值（油價以字串儲存，如 `"30.3"`） |
| `updated_at` | TIMESTAMPTZ | 最後更新時間 |

初始資料列：
- `fuel_price_92` → `"30.3"`
- `fuel_price_95` → `"32.5"`
- `fuel_price_98` → `"34.5"`
- `service_fee_tier1` → `"10"`（0–10 km）
- `service_fee_tier2` → `"15"`（11–30 km）
- `service_fee_tier3` → `"20"`（>30 km）

Migration 檔：`supabase/migrations/002_add_map_fields.sql`

### 新增 API 代理路由

| 路由 | 說明 |
|------|------|
| `/api/directions` | 代理 Google Directions API |
| `/api/geocode` | 代理 Google Geocoding API（座標 → 地址） |

### 環境變數
`NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`（需在 GCP 額外啟用 Maps JavaScript API、Directions API、Geocoding API）

## 9. 備註

- 車型油耗數值來源：交通部能源局 ecocar.artc.org.tw，官方值 × 1.15 市區修正係數
- 司機不得手動修改油耗與油號，須在「個人資料 → 車輛設定」選擇車型類別（8 種），系統自動帶入
- 油號依車型類別固定預設（小/中型 → 95；大型/大 SUV → 98；電動車 → N/A），防止司機選高油號多報油資
- 油價每週四自動從台灣中油（CPC）官網爬取，存入 `system_config` 表（`fuel_price_92/95/98`）；初始手動填值
- 平台服務費分三級：$10（≤10km）/ $15（11–30km）/ $20（>30km），後台可調整金額與分界
- 企業訂閱管理由後台 `/admin/companies` 操作（`subscription_active` 開關）
- Directions API 計費：每 1,000 次請求約 $5 USD；發布行程與行程詳情各呼叫一次
- 建議安裝套件：`@googlemaps/js-api-loader`（統一管理 Maps script 載入）
- GPS 定位僅用於出發地；終點依使用者習慣手動輸入或地圖選點
- 行程詳情路線地圖固定使用「開車」模式（符合共乘使用情境）
