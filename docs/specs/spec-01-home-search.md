# 首頁搜尋 功能規格書

**版本：** v1.0
**日期：** 2026-03-16
**狀態：** 已完成

---

## 1. 背景與目標

員工上班前不知道有沒有人願意共乘，也不知道去哪裡找到順路的同事。首頁是使用者進入平台後第一個接觸的畫面，必須讓人在 10 秒內理解平台用途並發起搜尋。

**目標：**
- 讓使用者能快速輸入出發地、目的地、日期，搜尋可共乘的行程
- 透過熱門路線快填降低輸入門檻
- 以 ESG 減碳數據強化品牌主張，提升使用者認同感

---

## 2. 使用者故事

- 身為**上班族員工**，我希望輸入起訖點和日期就能找到共乘行程，這樣才能快速配對上同路的同事。
- 身為**第一次使用的新用戶**，我希望看到熱門路線推薦，這樣才能不用從零開始打字。
- 身為**企業 ESG 負責人**，我希望在首頁就能看到企業整體減碳成果，這樣才能感受到平台帶來的實際效益。

---

## 3. 功能範圍

### 已完成功能
- 綠色漸層 Header，顯示平台名稱與標語
- 搜尋卡片：出發地、目的地、出發日期三個輸入欄位
- 三個欄位都填才能點擊搜尋按鈕（否則按鈕 disabled）
- 點擊搜尋後顯示 Loading spinner，1 秒後跳轉至 `/results`
- 熱門路線快填（3 條，點擊自動帶入出發地與目的地）
- ESG 本月企業減碳成果 Banner（靜態數字）

### 待製作
- 地點自動完成（需串接地圖 API）
- 真實後端搜尋（目前以 mock data 展示）
- 個人化歷史搜尋記錄
- 搜尋按鈕加上 `aria-label` 無障礙標籤

---

## 4. 使用流程

**成功路徑：**
1. 使用者開啟 `/`，看到首頁
2. 在「出發地」欄位輸入文字（或點擊熱門路線快填自動帶入）
3. 在「目的地」欄位輸入文字
4. 在「出發日期」欄位選擇日期（日期選擇器，最早只能選今天）
5. 三個欄位都填完後，「尋找順路車」按鈕變為可點擊
6. 點擊按鈕 → 按鈕切換為 Loading 狀態（轉圈動畫 + 「搜尋中...」文字）
7. 約 1 秒後跳轉至 `/results?from=...&to=...&date=...`

**例外情況：**
- 欄位未填完 → 按鈕維持 disabled，點擊無效果

## 5. 畫面與功能說明

**路由：** `/`
**是否需要登入：** 否

### Header 區塊
- 綠色漸層背景（`from-green-600 to-emerald-500`）
- 左上角 Logo 圖示 + 「揪車 JiuChe」標題
- 副標題：「企業 ESG 減碳共乘平台」
- 標語文字：「找順路夥伴，一起上班，一起減碳 🌿」

### 搜尋卡片（白色圓角卡片，-mt-5 疊在 Header 上）
| 欄位 | 類型 | 說明 |
|------|------|------|
| 出發地 | text input | placeholder「輸入出發地點」，focus 時邊框轉綠 |
| 目的地 | text input | placeholder「輸入目的地點」，focus 時邊框轉綠 |
| 出發日期 | date input | 最早只能選今天（`min={today}`） |

- 出發地與目的地中間有虛線分隔 + 向下箭頭圖示
- 搜尋按鈕：全寬、綠色漸層，三欄未填完時 `opacity-50` 且 cursor-not-allowed
- Loading 狀態：轉圈 SVG 動畫 + 「搜尋中...」文字，按鈕維持 disabled 防止重複觸發

### 熱門路線區塊
3 條固定路線，點擊後自動帶入出發地與目的地欄位：
| 出發地 | 目的地 | 顯示減碳量 |
|--------|--------|-----------|
| 捷運市政府站 | 南港軟體園區 | 1.2 kg CO₂ |
| 板橋車站 | 內湖科學園區 | 2.4 kg CO₂ |
| 新店總督府 | 信義計畫區 | 1.8 kg CO₂ |

### ESG Banner
- 翠綠漸層背景（`from-emerald-500 to-teal-500`）
- 顯示：本月企業共完成 **1,247** 趟共乘，減少排放 **2.3 噸** CO₂
- 靜態數字，無互動

---

## 6. 資料說明

- **搜尋輸入值**：僅透過 URL query string 傳遞給 `/results` 頁面（`from`、`to`、`date`），不儲存在 localStorage
- **熱門路線**：寫死在 `page.tsx` 內（非來自 `mockData.ts`）
- **ESG Banner 數字**：靜態 hardcode（1,247 趟 / 2.3 噸），非動態計算
- **今日日期**：由 `new Date().toISOString().split("T")[0]` 取得，作為日期欄位的 `min` 值

---

## 7. 設計規範

- 手機優先設計，最寬 448px（`max-w-md`）
- 頁面載入無明顯跳動（搜尋卡片以 -mt-5 疊在 Header 上，非動態插入）
